# 독서인문학 10조 발표자료

호프 자런(Hope Jahren)의 **《나는 풍요로웠고 지구는 달라졌다》** 4부 ‘지구’ 편을 바탕으로 제작된 인터랙티브 프레젠테이션 웹 슬라이드입니다.

## 👥 발표 조
- **10조**: 신동수, 김예지, 인용석

## 🎮 슬라이드 제어 방법
- **다음(진행)**: 화면 우측 클릭 / `Space` / `→` (우측 방향키)
- **이전(되돌리기)**: 화면 좌측 클릭 / `Backspace` / `←` (좌측 방향키)
- **전체화면**: `F` 키 또는 우측 상단 전체화면 아이콘

## 🌐 웹에서 바로 보기 (GitHub Pages)
GitHub 저장소의 `Settings` > `Pages` > `Deploy from a branch` (main / root) 설정을 통해 바로 호스팅됩니다.
